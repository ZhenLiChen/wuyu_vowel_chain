# S0–S3 主体层链形聚类：算法与当前结果

本文档记录 `佳皆—麻—歌戈—模` 四个链位的点级主体层聚类口径、当前三类结果和制图规则。对应脚本为 `scripts/cluster_mainlayer_chains.py`。

## 1. 数据与分析单位

- 输入：`data_raw/mainlayer_merge.csv`。
- 样本：82 个方言点，每点有 `K / M / P / TS / Ø` 五类声母条件，共 410 行。
- 链位顺序固定为 `S0 → S1 → S2 → S3`，分别对应 `佳皆 → 麻 → 歌戈 → 模`。
- 各 slot 的构拟 initial 只用于说明来源和方向，不作为现代音值坐标，也不画入图中。
- 聚类单位是“方言点”，不是“声母条件”。因此先把同一方言点、同一 slot 下的五个声母条件压缩为一个点级代表音值。

点级代表音值不是坐标平均值，而是该格实际出现过的 IPA 值中的 medoid：选择与其余声母条件音值总距离最小的实际音值。若成本并列，先选频次高者，再按 IPA 字符排序。这样不会构造材料中不存在的平均元音。

同时保留以下审计字段：

- `S*_all_onset_values`：五类声母条件的全部音值及频次。
- `S*_dispersion`：该 slot 内部声母条件相对代表音值的平均距离。
- `S*_is_diphthong`：点级代表音值是否为复元音。

## 2. IPA 音值距离

单元音的起点和终点相同；复元音保留书写顺序中的首、末元音。聚类不只比较复元音中点，而是比较有方向的起止位置：

```text
d_position(a,b)
  = 0.5 × [d(a.start,b.start) + d(a.end,b.end)]

d_value(a,b)
  = d_position
  + 0.03 × 起点/终点圆唇属性不一致数
  + 0.12 × 单元音/复元音结构不一致
```

舌位距离中，高低维保持完整权重；前后维乘以 `0.35`。这使聚类首先反映升降链形，同时仍保留前后差异。`u` 与 `ɯ` 因舌位接近，只通过较小的圆唇惩罚区分。

两个方言点的链距离是四个对应 slot 音值距离的算术平均：

```text
d_chain(A,B) = mean[d(S0A,S0B), d(S1A,S1B), d(S2A,S2B), d(S3A,S3B)]
```

slot 顺序不会互换，因而 `S2` 先裂化和 `S3` 先裂化会被视为不同链形。

## 3. 聚类方法与类别数

使用 k-medoids，而不是 k-means。原因是每类的代表必须是一个材料中实际存在的方言点，不能是难以解释的坐标均值。每个 `k` 使用固定随机种子和 240 次随机重启，并加入 farthest-first 初始解；测试范围为 `k=2…8`。

| k | silhouette | 类别规模 |
|---:|---:|---|
| 2 | 0.4018 | 60 / 22 |
| 3 | 0.4835 | 18 / 21 / 43 |
| 4 | 0.4747 | 15 / 21 / 3 / 43 |
| 5 | 0.4076 | 13 / 20 / 21 / 3 / 25 |
| 6 | 0.4526 | 13 / 20 / 17 / 4 / 3 / 25 |
| 7 | 0.4994 | 13 / 19 / 17 / 4 / 22 / 3 / 4 |
| 8 | 0.5135 | 13 / 16 / 17 / 4 / 4 / 21 / 3 / 4 |

最终选类规则固定为：先排除任何类别少于 5 个方言点的解，再在合格解中选择 silhouette 最高者。`k=4…8` 均包含 3–4 点的过小类别；合格的 `k=2` 与 `k=3` 中，`k=3` 的 silhouette 更高，因此脚本自动选择 `k=3`。这不是完全手选，也不是只追求 silhouette 最大值，而是在“分离度”和“类别可解释规模”之间使用一个明确、可复现的约束。

项目仍保存 `k=2…8` 的标签供审计，但最终图固定呈现推荐的三类结果，不再提供任意切换类别数的控件。

## 4. 当前三类结果

连续 slot 只有在“IPA 值相同且舌位坐标相同”时才合并显示。例如 `S2=u, S3=u` 写成 `S2–S3 u`，不重复画零位移箭头。

| 类别 | 类型结论 | 点数 | 主模式 | k-medoids 代表方言点 | S3 点级复元音数 |
|---:|---|---:|---|---|---:|
| 1 | S1–S2 O并位型 | 18 | `S0 a → S1–S2 o → S3 u` | KQ01 柯桥 | 0 |
| 2 | S2 前增生复元音型 | 21 | `S0 a → S1 o → S2 əu → S3 u` | FH01 奉化西坞 | 4 |
| 3 | S2–S3 U并位型 | 43 | `S0 ᴀ → S1 o → S2–S3 u` | BS01 宝山 | 1 |

“奉化西坞”不是另加的一条链，而是第二类的实际 medoid。图中统一称为“代表方言点”。补充的逐方言点链位图是独立检查区，通过下拉框查看任一点，不再把奉化固定成额外示例。

## 5. S3 复元音并非不存在

按本聚类使用的“点级代表音值”口径，82 点中有 5 点的 S3 为复元音：

| 方言点 | 默认类别 | S3 | 压缩后的点级链 |
|---|---:|---|---|
| HZ02 湖州市区 | 3 | `əu` | `S0 a → S1 ɷ → S2 u → S3 əu` |
| KS01 昆山市区玉山镇 | 2 | `əu` | `S0 a → S1 o → S2–S3 əu` |
| SZ01 苏州城区 | 2 | `əu` | `S0 ɑ → S1 o → S2–S3 əu` |
| WX01 无锡城区 | 2 | `əɯ` | `S0 a → S1 u → S2–S3 əɯ` |
| WX02 吴县光福镇 | 2 | `əu` | `S0 a → S1 o → S2–S3 əu` |

三类主模式的 medoid 恰好都不是“S3 单独裂化型”，所以只看三条粗实线会漏掉这五点。它们在类内 S3 分布中以粉色复元音标记保留，也可在逐方言点链位图中单独查看。

这与声母条件层面的裂化统计不矛盾。`docs/s0_s3_diphthongization_analysis.md` 按“某点任一声母条件是否出现清晰裂化”统计，S3 有裂化的方言点为 27 个；本聚类先把五类声母条件压成一个 medoid，只有复元音成为该点 S3 主体值时才计为上述 5 点。两个数字回答的问题不同。

## 6. 当前制图编码

- 粗黑实线：该类 k-medoids 主模式，箭头按 `S0 → S1 → S2 → S3`。
- 大号实心节点及文字：主模式的链位和 IPA 值；`S0` 蓝、`S1` 橙、`S2` 绿、`S3` 粉。
- 小号淡色节点：同类其他方言在对应 slot 上的实际分布，颜色与该 slot 的主节点一致。不再绘制连接离散点的三角形或凸包。
- 圆点表示单元音；菱形表示复元音。
- 同一方言中完全重合的连续链位在主模式上合并标注，不重复画零位移箭头。
- 复元音绘在两个成分的 IPA 几何中点，例如 `əu` 位于 `ə` 与 `u` 之间；图上不另画复元音内部轨迹。聚类距离仍同时比较有序的起点和终点。
- 图下方另设“逐方言点链位图”，可以检查全部 82 点中的任一点；它是数据审计视图，不是第四种聚类类型。

## 7. S0 的 `i-` 起始音值

“S0 很多像 `ia`”在词项层面是成立的，但在当前点级主体链图里不明显，原因是两个统计层级不同：

- 全部 S0 词项中，`i-` 起始音值有 461/4729 条（9.7%），分布于 79/82 个方言点。
- 在进入聚类的“方言点 × 五类声母”主体值中，只有 13/410 格（3.2%）以 `ia/iɑ/iɛ/iᴀ` 为主体：K 类 8 格、TS 类 2 格、Ø 类 3 格，M/P 类为 0。
- 文读中 `i-` 起始比例是 33/96（34.4%），主体层中是 428/4633（9.2%）。因此它确实明显偏向文读，但不能简单等同于文读：绝对数量上仍有 428 条属于主体层，而且主要集中在 K 类声母环境（359 条），反映了声母条件作用。

当前主链图先把五类声母压成一个点级 medoid，所以少数声母条件中的 `ia` 往往被该点更高频的 `a/ɑ/ᴀ` 覆盖。若要专门讨论文白层或 K 类条件，应该另画 S0 的声母分层图，而不应让它直接改变本图的点级主链。

## 8. `uo` 为什么需要单独保留

`uo` 虽然与 `o` 具有相同的绘图末端，但结构顺序不同。当前材料中有 3 个点的点级主体值为 `S1 uo`：FY02 富阳东梓关、TL01 桐庐镇、YQ01 於潜；三者均为 `S0 a → S1 uo → S2–S3 u`。它们在推荐的三类解中归入第三类，但不能因此解释成普通的 `S1 o`。

图中不画 `u → o` 的内部轨迹，而是在第三类标题下明确列出 `S1 uo ×3`，并以菱形保留复元音身份。`k=8` 时，这三个 `uo` 点与 CS02 常熟虞山镇组成一个 4 点小类，代表链正是 `S0 a → S1 uo → S2–S3 u`；这说明该模式在更细切分中确实会浮现，只是因样本数太小，没有被采用为最终大类。

## 9. 其他聚类方式

当前 k-medoids 适合作为主结果，因为它允许自定义 IPA/顺序距离，并保证每类代表链来自真实方言点。更适合补充检验的方法是“层次聚类＋混合距离”：连续部分使用 IPA 舌位距离，类别部分把 `单元音 / uo 型 / ou、əu 型 / 其他复元音型` 当作有序结构特征，再用 bootstrap 检查分支稳定性。它比单纯 k-means 更适合保留 `uo` 这种数量少但理论上重要的模式。

不建议直接使用普通 k-means：它会产生不存在于材料中的平均元音。DBSCAN/HDBSCAN 可以寻找小型异常群，但对 82 个点和距离阈值较敏感，更适合作为探索性检查，不宜直接替代主分类。下一步若要决定 `uo` 是否正式独立成类，应比较当前 k-medoids 与“结构加权层次聚类”的 bootstrap 稳定度，而不是只看 silhouette。
