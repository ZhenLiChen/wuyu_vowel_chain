# 方言点强度聚类与结构类型说明

这份说明文档专门解释两件事：

1. 为什么这里既要做 `k-means`，又要做“结构类型分类”。
2. 新生成的每张图分别在说明什么，应该怎么读。

这部分分析用到的脚本是：

```text
scripts/analyze_point_structure_types.py
```

主要输出目录是：

```text
data_clean/merge_analysis/structure_type_analysis/
figs/structure_type_analysis/
```

## 1. 为什么要做两条线

这里其实在回答两个不同的问题。

### 1.1 k-means 回答的是“强度上像不像”

已有的 `k-means` 聚类是基于每个方言点的三个平均合并强度：

```text
avg_S0_S1
avg_S1_S2
avg_S2_S3
```

所以它本质上是在问：

> 哪些方言点在“数值强弱分布”上彼此接近？

例如：

- 有的点 `S1-S2` 特别强；
- 有的点 `S2-S3` 特别强；
- 有的点三段都不算很高。

这种聚类很适合描述“强度梯度类型”或“数值相似性类型”。

但它有一个限制：

> `k-means` 只能看到“强弱像不像”，不直接告诉你“这些点到底是哪一种音系结构”。

也就是说，两个点的平均强度可以很接近，但它们的链位等同方式不一定完全相同。

### 1.2 结构类型分类回答的是“到底是哪种关系结构”

结构类型分类不是看平均强度像不像，而是直接看四种基础链位关系：

```text
S2 = S3
S1 = S2
S0 = S1
S1 = S3
```

然后再问：

> 对某个方言点来说，这几种关系里到底哪一种最常出现？是单一主导，还是连锁出现，还是双段并存？

所以结构类型更接近音系解释。

例如：

- `S2=S3主导型`
- `S1=S2主导型`
- `S0=S1主导型`
- `S1=S2=S3连锁型`
- `S0=S1 与 S2=S3双段型`

这类标签可以直接拿去写语言学描述，因为它已经把“哪些链位在一起”等关系说出来了。

### 1.3 两条线的关系

所以最简单的理解是：

```text
k-means = 数值梯度聚类
structure type = 音系结构分类
```

前者看“像不像”，后者看“是什么”。

它们不是互相替代，而是互相补充：

- `k-means` 帮你看整体强度空间里有没有明显的数值类型。
- `structure type` 帮你把这些数值类型翻译成更可解释的链位关系结构。

## 2. 这次结构类型到底怎么定义

这次不再用 `A/B/C/D` 那种抽象字母来讲，而直接用链位关系。

四种基础关系是：

```text
S2 = S3
S1 = S2
S0 = S1
S1 = S3
```

每个方言点在 7 个声母条件位置上，都会被编码成这四种关系有没有出现。

其中：

- `N` 和 `T` 这两个特殊位置，只能观察 `S2=S3`；
- `K / M / P / TS / Ø` 这五类位置，可以观察四种关系。

这里最重要的一点是：

> `N/T` 对 `S1=S2`、`S0=S1`、`S1=S3` 是“结构性缺项”，不是 0。

也就是说：

- 看不到，不等于“不发生”；
- 真正观测到“不等”，才是 0。

这也意味着：

> `N/T` 的“合流/分立”只能看成整套结构在 `S2-S3` 这一段上的局部投影。

例如：

- `N/T = 合流` 表示该条件下 `S2=S3`
- `N/T = 分立` 表示该条件下 `S2≠S3`

它们确实可以看成更完整结构的“弱化版本”或“局部切片”，但不能单独代表整条链的全貌。  
特别是：

> `N/T = 分立` 和“全不等/保守分立型”往往有关，但它本身不是充分条件，因为 `N/T` 只能看得到 `S2-S3`，看不到 `S0-S1` 和 `S1-S2`。

## 3. 现在的结构类型标签是什么意思

目前脚本会给出这些结构类型：

### 3.1 `S2=S3主导型`

意思是：

> 高链位 `S2` 和 `S3` 的等同最强、最常见。

这是现在最常见的类型。

### 3.2 `S1=S2主导型`

意思是：

> 中链位 `S1` 和 `S2` 的等同最强。

这种类型数量比 `S2=S3主导型` 少，但分布很集中，常常会形成很清楚的区域性。

### 3.3 `S0=S1主导型`

意思是：

> 低链位 `S0` 和 `S1` 的等同最强。

目前数量很少，所以更像边缘类型，而不是全局主流。

### 3.4 `S1=S2=S3连锁型`

意思是：

> `S1=S2` 和 `S2=S3` 同时都很强，说明中高链位已经形成连锁合并。

这类点在语言学上很重要，因为它往往不只是局部相邻合并，而是一个连续链段的重组。

### 3.5 `S0=S1 与 S2=S3双段型`

意思是：

> 低段有一组合并，高段又有一组合并，但中间不一定完全连起来。

这种类型可以理解为“双段并行靠拢”，而不是整条链连续压缩。

### 3.6 `S0=S1=S2=S3全链趋同型`

意思是：

> 整条链位都在朝高度趋同发展。

这类如果出现，会很强烈地暗示整体系统收缩。

### 3.7 `S1=S3显性跨链位型`

意思是：

> 直接出现了 `S1=S3` 这种跨链位等同，而不只是相邻链位逐步连起来。

它值得特别关注，因为这种关系在结构上不是最普通的局部合并，而更像“跳接”。

### 3.8 `保守分立型`

意思是：

> 在大多数可观察位置上，各链位仍然保持分立，只出现很弱、很零星的局部等同。

这类点通常有几个特点：

- 五个普通声母条件里，多数是 `全对立`
- 即使出现合并，也往往只是零星的 `S2=S3`
- `S1=S2`、`S0=S1`、`S1=S3` 基本不出现

所以更准确地说，它不是“混合”，而是：

> 整体仍然偏保守，只在高链位局部出现一点点松动

### 3.9 `混合过渡型`

意思是：

> 已经不再是简单分立，但又还没有稳定成单一主导结构。

这类点和 `保守分立型` 不一样：

- `保守分立型` 是“基本都不等，只偶尔局部合流”
- `混合过渡型` 是“真的有多种关系并存，但尚未稳定”

## 5. 为什么 k-means 不能直接替代结构类型

因为 `k-means` 只能看到平均强度，结构类型则在看“到底是哪几段在等同”。

最典型的例子是：

- 一个点可能 `S2-S3` 很强，所以被 `k-means` 放进同一类；
- 但它内部也可能同时带一点 `S0=S1`；
- 另一个点虽然同样 `S2-S3` 很强，却几乎没有低段关系。

它们在 `k-means` 看来可能都属于同一数值类，但结构解释并不完全一样。

所以更稳妥的工作流是：

```text
七个声母条件列
→ 还原成四种基础链位关系
→ 计算每点的关系强度
→ 保留并检查既有 k-means 强度聚类
→ 新增规则型 structure_type
→ 再去看地理分布、声母条件、结构关联
```

## 6. 每张图是什么意思

### 6.1 `cluster_center_heatmap.png`

文件：

```text
figs/structure_type_analysis/cluster_center_heatmap.png
```

这张图看的是：

> 每个 k-means cluster 的平均中心长什么样

行是 cluster，列是强度变量，包括：

- `avg_S0_S1`
- `avg_S1_S2`
- `avg_S2_S3`
- `S2=S3` 强度
- `S1=S2` 强度
- `S0=S1` 强度
- `S1=S3` 强度

读法：

- 哪一列颜色最深，说明该 cluster 最突出的关系在哪。
- 如果 `avg_S1_S2` 和 `S1=S2` 都很高，那就是典型 `S1=S2` 型强度类。
- 如果 `avg_S2_S3` 和 `S2=S3` 都很高，那就是典型 `S2=S3` 型强度类。

这是理解“强度聚类”的核心图。


这张图看的是：

## 7. 地图该怎么配合解释

最推荐的方式不是只给一张图，而是把两张地图配合起来看：

1. 先看 `map_kmeans_cluster.png`
   说明不同地区在“强度梯度”上确实分群。

2. 再看 `map_structure_type.png`
   说明这些分群在音系上分别对应什么结构。

这样逻辑就完整了：

```text
地理区域
→ 呈现不同的数值强度梯度
→ 这些梯度又对应不同的链位结构类型
```

换句话说，地图的价值不只是“好看”，而是帮助你把：

```text
数值聚类
结构类型
地理分布
```

三者连起来。

## 8. 目前最简洁的结论

如果要把这一部分压缩成最容易懂的话，可以这样说：

1. `k-means` 告诉我们，方言点在合并强度上确实可以分成几类，主要是 `S1-S2` 强类、`S2-S3` 强类和整体较弱类。
2. 但 `k-means` 只是数值相似性，不等于音系结构。
3. 把七个声母条件统一还原为 `S2=S3 / S1=S2 / S0=S1 / S1=S3` 四种基础关系以后，可以进一步看出哪些点是 `S2=S3主导型`，哪些是 `S1=S2主导型`，哪些其实是 `保守分立型`，哪些才是真正的 `混合过渡型`。
4. 两种方法结合起来看，才既能保留数值梯度信息，又能给出更可解释的链位结构类型。
